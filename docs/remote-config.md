# Удалённые проекты

- **Версия документа:** 1.0.0
- **Статус:** реализовано
- **Обновлено:** 2026-08-09

## Назначение

Файл `remote/remotes.json` вручную описывает проекты, которые уже запущены на
других машинах локальной сети. Каждый удалённый Launcher работает независимо.

## Формат

```json
{
  "remoteMachines": [
    {
      "id": "macbook-air",
      "name": "MacBookAir",
      "host": "192.168.1.56",
      "projects": [
        {
          "id": "trade-actu",
          "name": "trade.actu",
          "port": 8050
        }
      ]
    }
  ]
}
```

## Поля

- `id` — стабильный идентификатор машины или проекта.
- `name` — название в меню.
- `host` — сетевое имя или IP удалённой машины.
- `port` — порт удалённого сервиса.
- `url` — необязательный полный URL проекта. Если отсутствует, Launcher формирует
  `http://<host>:<port>`.

Удалённый сервис должен слушать сетевой интерфейс, например `0.0.0.0`, и быть
доступен с текущей машины. Launcher не запускает и не останавливает его.
