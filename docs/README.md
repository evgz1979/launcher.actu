# Документация Launcher

- **Версия документа:** 3.1.0
- **Статус:** актуальный индекс
- **Обновлено:** 2026-08-09

Здесь описана согласованная архитектура обнаружения локальных Python-проектов,
описания их сервисов и формирования конфигурации для macOS Launcher.

## Разделы

- [Архитектура](architecture.md) — компоненты, расположение файлов и поток данных.
- [Проектный `launcher.json`](project-config.md) — формат описания сервисов проекта.
- [Scanner CLI](scanner-cli.md) — сканирование, интерактивные вопросы, проверка и
  обновление машинной конфигурации.
- [Удалённые проекты](remote-config.md) — ручная настройка ссылок на сервисы
  других машин.
- [Версии документации](VERSIONS.md) — правила версионирования и история
  выпусков документов.

## Статус

Документы фиксируют архитектуру, реализованную 9 августа 2026 года. Launcher
выбирает конфигурацию машины из `configs/` по macOS `LocalHostName`, а Scanner
CLI формирует её из проектных `launcher.json`.

Согласно корневому `AGENTS.md`, реализация начинается только после явного
разрешения пользователя.
