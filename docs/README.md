# Документация Launcher

- **Версия документа:** 4.0.0
- **Статус:** актуальный индекс
- **Обновлено:** 2026-08-29

Документация описывает прямое обнаружение локальных проектов приложением
Launcher, формат проектных конфигураций и вспомогательный Scanner CLI.

- [Scanner CLI](scanner-cli.md) — создание, проверка и просмотр проектных файлов.
- [Удалённые проекты](remote-config.md) — ручная настройка сетевых ссылок.
- [Версии документации](VERSIONS.md) — история несовместимых и совместимых
  изменений.

## Текущий контракт

Launcher при каждом старте сканирует непосредственные дочерние каталоги
`~/Documents` и загружает только каталоги с корневым `launcher.json`. Машинные
файлы из `configs/` приложением больше не читаются.
