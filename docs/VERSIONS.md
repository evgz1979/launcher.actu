# Версии документации

- **Версия документа:** 4.0.0
- **Статус:** актуальный журнал
- **Обновлено:** 2026-08-29

## Правила версионирования

Документация использует Semantic Versioning:

- `MAJOR` — несовместимое изменение архитектуры, формата или рабочего процесса;
- `MINOR` — новое совместимое поведение или существенный раздел;
- `PATCH` — исправление или уточнение без изменения контракта.

## Выпуски

### 4.0.0 — 2026-08-29

- Launcher перешёл с машинных JSON на прямое сканирование непосредственных
  папок `~/Documents` с корневым `launcher.json`.
- Проектные файлы стали единственным источником локальных сервисов.
- Относительные команды разрешаются приложением от корня каждого проекта.
- Автоматически запускаются только сервисы с явным `autoStart: true`.
- Scanner CLI больше не создаёт и не проверяет машинные конфигурации; `check` и
  `show` работают с каталогом проектов.
- Добавлена проверка повторяющихся ID проектов и сервисов.
- Вывод дочерних процессов постоянно дренируется в системный лог, поэтому
  длительно работающий Datafeeder не блокируется после заполнения pipe.

### 3.1.1 — 2026-08-09

- Исправлено разрешение пути `.venv/bin/python`: абсолютный путь сохраняет
  символическую ссылку виртуального окружения и его зависимости.

### 3.1.0 — 2026-08-09

- Добавлен ручной файл `remote/remotes.json` для сетевых сервисов других машин.
- Удалённые машины показываются отдельными группами в меню Launcher.

### 3.0.0 — 2026-08-09

- Scanner CLI автоматически определяет порт и URL из README и Python AST.
- Отдельный пункт `Open` удалён; ручной `Start` открывает браузер после запуска.

### 2.2.0 — 2026-08-09

- После записи изменённой конфигурации Scanner CLI автоматически перезапускает
  работающий Launcher.

### 2.1.0 — 2026-08-09

- Упрощено интерактивное создание проектного `launcher.json`.
- ID, названия, интерпретатор и точки входа определяются автоматически.

### 2.0.0 — 2026-08-09

- Удалён постоянный список `ignoredProjects`.
- Постоянное отключение перенесено в `enabled: false` проектного файла.

### 1.1.0 — 2026-08-09

- Scanner CLI переведён в реализованное состояние.
- Добавлен ручной запуск Scanner CLI из меню Launcher.

### 1.0.0 — 2026-08-09

- Зафиксированы первая архитектура Launcher, Scanner CLI, машинных конфигураций
  и проектного формата версии 1.
