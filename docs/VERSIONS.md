# Версии документации

- **Версия документа:** 3.1.0
- **Статус:** актуальный журнал
- **Обновлено:** 2026-08-09

## Правила версионирования

Документация использует Semantic Versioning (`MAJOR.MINOR.PATCH`):

- `MAJOR` увеличивается при несовместимом изменении архитектуры, формата
  конфигурации или обязательного рабочего процесса;
- `MINOR` увеличивается при добавлении нового поведения, сценария или
  существенного раздела без нарушения ранее описанного контракта;
- `PATCH` увеличивается при исправлении ошибки, уточнении формулировки,
  обновлении примера или другом совместимом изменении.

Версия указывается отдельно в каждом документе. При изменении документа его
версия и запись в этом журнале обновляются вместе.

## Выпуски

### 3.1.0 — 2026-08-09

- Добавлен ручной файл `remote/remotes.json` для сетевых сервисов других машин.
- Удалённые машины показываются отдельными группами в меню Launcher.
- Нажатие на удалённый проект открывает его URL без удалённого управления.

### 3.0.0 — 2026-08-09

- Scanner CLI автоматически определяет порт и URL из README и Python AST.
- Однозначно определённые значения исправляют ранее созданные проектные
  конфигурации.
- Отдельный пункт `Open` удалён из меню Launcher.
- Ручной `Start` запускает сервис и открывает браузер; автоматический запуск
  браузер не открывает.

### 2.2.0 — 2026-08-09

- После успешной записи изменённой конфигурации Scanner CLI автоматически
  перезапускает работающий Launcher.
- Перезапуск не выполняется, если изменений нет или Launcher не был запущен.

### 2.1.0 — 2026-08-09

- Упрощён интерактивный опрос при создании проектного `launcher.json`.
- ID и названия проекта и сервисов формируются автоматически.
- Python-интерпретатор и точки входа определяются по структуре проекта.
- Пользователь задаёт только порт, URL, автозапуск и подключение дополнительных
  найденных сервисов.

### 2.0.0 — 2026-08-09

- Удалён постоянный список `ignoredProjects` для отдельных машин.
- Scanner CLI теперь рассматривает все проекты текущей машины при каждом
  сканировании.
- Отказ от добавления означает разовый пропуск; постоянное отключение задаётся
  проектным `launcher.json` с `enabled: false`.

### 1.1.0 — 2026-08-09

- Scanner CLI переведён из согласованного проекта в реализованное состояние.
- Задокументированы фактические команды запуска и параметры каталогов.
- Уточнено, что CLI написан на Python без внешних зависимостей.
- Добавлена конфигурация ручного запуска Scanner CLI из меню Launcher.

### 1.0.0 — 2026-08-09

Первый зафиксированный выпуск русскоязычной документации:

- архитектура Launcher, Scanner CLI и машинных конфигураций;
- проектный формат `launcher.json` версии 1;
- правила обнаружения Python-проектов в `~/Documents`;
- интерактивное создание конфигураций и обработка отказов;
- требования безопасности и ограничения первой реализации;
- инструкции по сборке и автозапуску Launcher.
