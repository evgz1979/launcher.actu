# Проектный `launcher.json`

- **Версия документа:** 4.0.0
- **Статус:** формат версии 1 реализован
- **Обновлено:** 2026-08-29

## Расположение и обнаружение

Каждый подключённый проект хранит `launcher.json` в своём корне:

```text
~/Documents/actu/launcher.json
```

Само наличие этого файла регистрирует непосредственный дочерний каталог
`~/Documents` как проект. `README.md`, Git и признаки конкретного языка для
обнаружения не требуются.

## Формат версии 1

```json
{
  "version": 1,
  "id": "actu",
  "name": "Actu",
  "enabled": true,
  "services": [
    {
      "id": "datafeeder",
      "name": "Datafeeder",
      "command": [".venv/bin/python", "datafeeder.py"],
      "port": 8051,
      "url": "http://127.0.0.1:8051",
      "autoStart": true
    },
    {
      "id": "viewer",
      "name": "Viewer",
      "command": [".venv/bin/python", "main.py"],
      "port": 8053,
      "url": "http://127.0.0.1:8053",
      "autoStart": true
    }
  ]
}
```

## Поля проекта

- `version` — обязательная версия формата; поддерживается `1`.
- `id` — обязательный стабильный идентификатор, уникальный среди включённых
  проектов каталога.
- `name` — обязательное название в меню.
- `enabled` — необязательное поле, по умолчанию `true`; `false` исключает проект
  из Launcher.
- `services` — обязательный массив, который может быть пустым.

## Поля сервиса

- `id` — обязательный уникальный внутри проекта идентификатор.
- `name` — обязательное название в меню.
- `command` — обязательный непустой массив команды и аргументов.
- `workingDirectory` — необязательный каталог; по умолчанию корень проекта.
- `port` — необязательный порт, освобождаемый перед запуском.
- `url` — необязательный HTTP- или HTTPS-адрес, открываемый после ручного старта.
- `autoStart` — необязательный флаг; автоматически запускается только явное
  значение `true`.

## Пути

Переносимые конфигурации используют относительные пути:

```json
"command": [".venv/bin/python", "main.py"]
```

Launcher напрямую преобразует первый элемент команды, содержащий путь, и
`workingDirectory` в абсолютные пути от корня конкретного проекта. Путь
`.venv/bin/python` сохраняется как путь виртуального окружения и не раскрывается
до физического интерпретатора.

Остальные аргументы команды остаются без изменений и выполняются в рабочем
каталоге проекта. Команды из `PATH`, например `python3`, абсолютными не
преобразуются.

## Проверка

Scanner CLI проверяет:

- корректность JSON и `version`;
- обязательные идентификаторы, названия и команды;
- уникальность ID сервисов;
- диапазон `port` и формат `url`;
- существование рабочего каталога и исполняемого файла;
- уникальность ID проектов в каталоге.

Команда проверки:

```bash
./scripts/launcher-config check
```
